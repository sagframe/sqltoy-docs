# TypeHandler Extension

Configure a handler class for special types such as json by extending sqltoy's abstract class:
org.sagacity.sqltoy.plugins.TypeHandler

## 1. Configuration

```yaml
sqltoy:
  typeHandler: com.example.sqltoy_solon_demo.handler.MyTypeHandler
```

## 2. Implementation Class

Create a MyTypeHandler class that extends org.sagacity.sqltoy.plugins.TypeHandler

```java
public class MyTypeHandler extends TypeHandler {
    @Override
    public boolean setValue(Integer integer, PreparedStatement ps, int parameterIndex, int i1, Object o) throws SQLException {
        if (parameterIndex == 1) {
            ps.setString(parameterIndex, "localhost");
            System.out.printf("setValue: %s ==> %s%n", o, "localhost");
            return true;
        }
        return false;
    }
}
```

## 3. JSONTypeHandler Example

* Note: since version 5.6.82 the framework provides built-in json/jsonb type support; upgrade quickvo to version 1.0.22, with jdbc-type=2016(json), 2017(jsonb)

### 3.1 Type Mapping for POJOs Generated by quickvo

```xml
<type-mapping>
		<!-- Keep one example; normally no configuration is needed -->
		<!-- Demo of adding the snowflake algorithm -->
		<sql-type native-types="BIGINT" jdbc-type="BIGINT" java-type="java.math.BigInteger" />

		<!-- Mind the xml escape characters for generics; table-field specifies the concrete table and field; jdbc-type can also be a plain number, here java-type="List<StaffInfoVO>" -->
		<sql-type table-field="sqltoy_jsontype_showcae.staff_set" native-types="json" jdbc-type="2016" java-type="List&lt;StaffInfoVO&gt;" 
		import-types="com.sqltoy.quickstart.vo.StaffInfoVO" />
</type-mapping>
```

### 3.2 Define JsonTypeHandler

```java
public class JsonTypeHandler extends TypeHandler {
	// Handle null as appropriate; this step is mandatory on postgresql
	@Override
	public boolean setNull(Integer dbType, PreparedStatement pst, int paramIndex, int jdbcType) throws SQLException {
		return false;
	}

	/**
	 * <li>Returning true means the type matched and the setValue assignment has been done</li>
	 * <li>Returning false means a regular type, handed back to the framework for default processing</li>
	 */
	@Override
	public boolean setValue(Integer dbType, PreparedStatement pst, int paramIndex, int jdbcType, Object value)
			throws SQLException {
		// Distinguish specific types by setting the int number directly in jdbc-type in quickvo.xml
		if (jdbcType == 1021) {
			pst.setString(paramIndex, JSONObject.toJSONString(value));
			return true;
		}
		return false;
	}

	/*
	 * <li>1. Returning null means it is a regular type, handed back to the framework for processing</li>
	 * <li>2. Returning non-null means a special type; the type conversion is done and the result can be mapped directly to the VO property</li>
	 */
	@Override
	public Object toJavaType(String javaTypeName, Class genericType, Object jdbcValue) throws Exception {
		if (javaTypeName.equalsIgnoreCase("java.lang.string")) {
			return jdbcValue.toString();
		}
		// A VO object
		if (javaTypeName.contains("com.sqltoy")) {
			return JSON.parseObject(jdbcValue.toString(), Class.forName(javaTypeName));
		}
		if (javaTypeName.toLowerCase().contains("jsonobject")) {
			return JSON.parse(jdbcValue.toString());
		} else if (javaTypeName.toLowerCase().contains("jsonarray")) {
			return JSONArray.parseArray(jdbcValue.toString());
		}
		// List<VO> form
		if (javaTypeName.equalsIgnoreCase("java.util.List") && genericType != null) {
			return JSONArray.parseArray(jdbcValue.toString(), genericType);
		}
		// Any other scenario means it is not json; return null and let the framework handle it
		return null;
	}
}
```
