# SqlToy Feature List

SqlToy starts from the cleanest dynamic-SQL authoring model, combining JPA-style object operations with the strongest native SQL querying. The full feature catalog by category — each row links to its detailed chapter.

## 1. Object Operations (JPA-style)

| Feature | Description | Details |
| --- | --- | --- |
| Object CRUD | Complete API set — save / saveAll / update / delete / load, etc. (~110 LightDao methods); annotated POJOs generated by quickvo | [Object CRUD（中文）](../../crud/sqltoy_crud.md) |
| Elastic update | One database interaction completes the update (unlike Hibernate's load-then-update); null fields are skipped, ensuring data accuracy under high concurrency | [Object CRUD（中文）](../../crud/sqltoy_crud.md) |
| updateFetch | Lock-query → logic validation → modify → return the latest result, all in one interaction; for flash sales, inventory and ledger accounts | [Object CRUD（中文）](../../crud/sqltoy_crud.md) |
| updateSaveFetch | Lock-query, insert when absent / update when present, returning the modified result | [Object CRUD（中文）](../../crud/sqltoy_crud.md) |
| updateByQuery | Batch single-table update by condition, supporting `set field=field+?` self-referencing expressions | [Object CRUD（中文）](../../crud/sqltoy_crud.md) |
| Cascade operations | `@OneToOne`/`@OneToMany` cascading save, load (with filtering/sorting), update and delete; batch cascade optimized with IN queries | [Object CRUD（中文）](../../crud/sqltoy_crud.md) |
| Query hierarchy packaging | One join SQL automatically packs parent-child tables into nested objects (1..n) per annotations | [Query API（中文）](../../query/sqltoy_query.md) |
| Tree-table route builder | `wrapTreeTableRoute` builds node route / level / leaf flags for non-recursive subtree queries | [Tree-Table Route（中文）](../../crud/tree_table.md) |
| Primary-key strategies | 22/26-digit ordered ids, snowflake, UUIDv7, ULID, sequence/identity, Redis rule-based business keys; custom extensions supported | [Primary Keys（中文）](../../primarykey/sqltoy_primarykey.md) |
| Data versioning | `@DataVersion` optimistic locking against concurrent overwrites | [Data Versioning（中文）](../../enterprise/data_version.md) |
| Common-field auto-fill | createdBy/updatedBy/createdTime/updatedTime/tenant filled automatically (can be paused/resumed) | [Auto-Fill（中文）](../../quickstart/helloworld_improve.md) |

| Feature | Description | Details |
| --- | --- | --- |
